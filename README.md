# 차량 소음 측정 (현장용 웹앱)

현장 기사님이 휴대폰만으로 차량 소음을 재고, **그 자리에서 정상 / 주의 / 초과 판정**을 보고, 결과를 **자동 저장·카톡 공유·보고서(PDF)·엑셀**로 넘길 수 있는 웹앱(PWA)입니다.
설치 없이 링크로 열고, "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다. 안드로이드(크롬)와 아이폰(사파리) 모두 됩니다.

![가로 화면](docs/preview-landscape.png)

## 기본 화면

앱을 열면 바로 **실시간 주파수 그래프**가 크게 나옵니다.

- 가로축: 주파수 (Hz, 1/3옥타브 25Hz–10kHz), 세로축: **A특성 적용 dB(A)**
- 가장 큰 대역은 진하게, 오른쪽 끝 막대는 **전체 소음도**(기준에 따라 초록·주황·빨강)
- 위: 현재 소음(큰 숫자), 평균·최대·주요 소리 / 아래: 측정 항목 선택, **측정 시작**
- 휴대폰을 **가로**로 돌리면 왼쪽은 그래프가 화면 가득, 오른쪽에 숫자와 버튼이 옵니다.

## 기사님 사용 흐름

1. **차량번호 입력** (처음 한 번만, 이후 기억함)
2. **측정 항목 선택**: 주행 실내 / 공회전 / 배기 / 이상음
3. **측정 시작** 한 번 누르기. 정해진 시간만큼 자동으로 잽니다. 측정 중에는 대역별 최대값이 가로선으로 남습니다.
4. 결과 화면: 큰 글씨로 **정상·주의·초과**, 기준선 막대, 주파수 그래프(평균 막대 + 최대 가로선), "어떤 소리인가요?"(저음·중음·고음 풀이)
   - 측정이 끝나면 결과를 **소리로 읽어 줍니다** (운전 중 화면을 안 봐도 됨)
   - **자동 저장**됩니다. 필요하면 메모·사진을 붙입니다.
5. **결과 보내기**: 결과 이미지 + 요약 글을 카톡·문자·메일로 공유

기록 화면에서 기간·차량으로 골라 **엑셀 파일(CSV)** 또는 **보고서(PDF, 결재란 포함)**를 만들 수 있습니다.

## 관리자 첫 설정

오른쪽 위 **설정** → 관리자 비밀번호 (처음 값 `0000`, 바로 바꾸세요)

| 항목 | 내용 |
| --- | --- |
| 회사 정보 | 회사 이름·팀 이름 (화면 위쪽, 공유 이미지, 보고서에 표시) |
| 판정 기준 | 항목별 주의 시작 / 초과 기준 dB(A), 측정 시간, 시작 전 대기 시간 |
| 마이크 보정 | **휴대폰마다 한 번씩** 정밀 소음계와 나란히 놓고 5초 측정 → 소음계 값 입력 |
| 기능 | 결과 음성 안내, GPS 위치 저장 켜기/끄기 |

처음 들어 있는 판정 기준은 **예시값**입니다. 회사 기준이나 관련 법규에 맞게 바꿔 주세요.

| 측정 항목 | 판정에 쓰는 값 | 예시 기준 (주의 / 초과) | 측정 시간 |
| --- | --- | --- | --- |
| 주행 중 실내 | 평균(LAeq) | 75 / 80 dB(A) | 15초 (시작 전 10초 대기) |
| 정차 공회전 | 평균(LAeq) | 55 / 65 dB(A) | 10초 |
| 배기 소음 | 최대(LAFmax) | 95 / 100 dB(A) | 8초 |
| 이상음 찾기 | 판정 없음, 주파수 분석 | – | 10초 |

> 설정과 보정값은 **각 휴대폰에 따로** 저장됩니다. 기사님 휴대폰마다 한 번씩 설정해 주세요.

## 배포 (GitHub Pages, 무료)

마이크는 https 주소에서만 켜지므로 웹에 올려야 합니다.

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
2. 기본 브랜치에 코드가 올라가면 `.github/workflows/pages.yml` 이 테스트 후 자동 배포합니다.
3. 주소는 `https://<계정>.github.io/<저장소>/` 형태입니다. 이 링크를 기사님들께 보내면 됩니다.

앱을 고친 뒤에는 `sw.js` 의 `VERSION` 을 올려야 휴대폰에 새 버전이 들어갑니다.

## 측정 방식

- 마이크 신호를 **A특성 필터**(IEC 61672 곡선, 디지털 필터)로 거른 뒤 표본 하나하나로 에너지를 계산합니다.
  - 평균 = **LAeq** (측정 시간 동안의 에너지 평균), 최대 = **LAFmax** (Fast, 125 ms 시간 가중)
- 처음 0.5초는 필터 안정화와 버튼 누르는 소리를 피하려고 버립니다.
- 주파수: 16384점 FFT(48 kHz에서 약 3 Hz 간격)를 **1/3옥타브 대역(25 Hz–10 kHz)** 으로 묶고 A특성을 적용합니다.
  결과에는 측정 시간 평균 스펙트럼, 대역별 최대값, 가장 두드러진 주파수(피크)가 저장됩니다.
  주변보다 10 dB 이상 튀면 "뚜렷한 소리"(윙~, 삐~ 같은 단일음)로 표시합니다.
- 브라우저의 에코 제거·잡음 제거·자동 음량 조절은 끄고 받습니다.

## 알아 둘 점

- **스마트폰 측정값은 참고값입니다.** 「소음·진동 공정시험기준」에 따른 법정 측정(정밀 소음계)을 대신하지 않습니다.
- 휴대폰 마이크는 대략 30–100 dB 범위에서 쓸 만합니다. 아주 큰 배기 소음은 마이크가 포화될 수 있고, 그러면 결과 화면에 경고가 뜹니다.
- 휴대폰 기종마다 감도가 다르니 **보정 전 값은 기기끼리 비교하지 마세요.**
- 기록은 **그 휴대폰 브라우저 안에만** 저장됩니다. 브라우저 데이터를 지우면 사라지니, 엑셀·보고서로 정기적으로 보내 두세요.
- 아이폰은 사파리에서 쓰던 기록과 "홈 화면에 추가"한 앱의 기록이 서로 따로 저장됩니다. 한쪽으로 정해서 쓰세요.
- 운전 중에는 휴대폰을 만지지 않도록, 주행 측정은 시작 전 대기 시간(기본 10초)을 두었습니다.

## 개발

빌드 도구·외부 라이브러리 없이 HTML/CSS/자바스크립트 모듈로 되어 있습니다.

```
index.html              화면 틀
css/app.css             스타일 (라이트/다크, 인쇄용)
js/app.js               화면과 이동 (홈, 측정, 결과, 기록, 보고서, 설정)
js/meter.js             마이크 측정 엔진 (Web Audio)
js/spectrum.js          큰 주파수 그래프 (캔버스, 실시간·결과 공용)
js/level-processor.js   AudioWorklet: A특성 필터, Leq, Fast 최대값
js/dsp.js               신호처리 순수 함수 (필터 설계, 옥타브, 피크, 판정)
js/settings.js          측정 항목 정의, 기본 기준, 설정 저장
js/store.js             기록 저장 (IndexedDB)
js/share.js             공유 이미지, 요약 글, CSV
js/charts.js, format.js 그래프와 표시 형식
sw.js, manifest.webmanifest, icons/   오프라인·홈 화면 설치
```

```bash
npm start                       # http://localhost:8080 (localhost 에서는 마이크 허용됨)
npm test                        # 신호처리 단위 테스트 (Node 22, 설치 불필요)
NODE_PATH=$(npm root -g) npm run test:e2e   # 크롬에 테스트 음을 마이크로 넣어 전체 흐름 확인 (playwright 필요)
```

E2E 테스트는 1 kHz·100 Hz 테스트 음(레벨을 아는 WAV)을 가짜 마이크로 넣고, 앱이 표시한 dB(A)·판정·주파수가 계산값과 0.5 dB 안에서 맞는지 확인합니다.
