# 실시간 소음 분석 (현장용 웹앱)

휴대폰 마이크로 소음을 **실시간 분석**하는 웹앱(PWA)입니다. 설치 없이 링크로 열고, "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다. 안드로이드(크롬)와 아이폰(사파리) 모두 됩니다.

![세로 화면](docs/preview.png)

![가로 화면](docs/preview-landscape.png)

## 화면

**실시간 분석 (기본 화면)**

- **FFT 스펙트럼**: 가로축 주파수(Hz, 로그 또는 선형), 세로축 **A특성 적용 dB(A)**
  - 빨강: 지금 스펙트럼, 회색: 측정 중 최대값(최대값 표시를 켰을 때)
  - 뚜렷하게 튀는 주파수 2개에 "1,250 Hz"처럼 표시하고, 오른쪽 위에 가장 큰 피크를 보여 줍니다.
- **현재 / 평균 / 최대 / 최소** dB(A), 측정 시간
- 세로: 그래프 아래에 **바늘 게이지**(20–130 dB, 경고 구간 주황), 일시정지·초기화·저장 버튼
- 가로: 그래프가 화면 가득, 숫자는 그래프 위에, 버튼은 아래 한 줄
- 그래프 설정: 최대값 표시/숨김, FFT 크기(2048 / 4096 / 8192 / 16384), 주파수 축(로그/선형)

**버튼**: ⏸ 일시정지(화면과 값 고정) · ⟲ 초기화(평균·최대·최소·최대 스펙트럼 다시 시작) · ⬇ 저장(지금 스펙트럼과 값을 차량번호·메모와 함께 저장)

**기록**: 저장한 분석 목록, 상세 화면(스펙트럼 그래프 + 값), 결과 이미지·요약 글 공유(카톡 등), 엑셀(CSV) 내보내기

**설정 (관리자 비밀번호, 처음 값 `0000`)**: 회사 이름, 게이지 경고 구간, **마이크 보정**, 비밀번호 변경, 기록 삭제

## 마이크 보정

휴대폰마다 마이크 감도가 달라서 **기기마다 한 번씩** 보정해야 값이 맞습니다.
설정 → 마이크 보정: 정밀 소음계와 나란히 두고 5초 측정 → 소음계 값 입력 → 적용. 보정값은 그 휴대폰에만 저장됩니다.

## 배포 (GitHub Pages, 무료)

마이크는 https 주소에서만 켜지므로 웹에 올려야 합니다.

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
2. 기본 브랜치에 코드가 올라가면 `.github/workflows/pages.yml` 이 테스트 후 자동 배포합니다.
3. 주소는 `https://<계정>.github.io/<저장소>/` 형태입니다.

앱을 고친 뒤에는 `sw.js` 의 `VERSION` 을 올려야 휴대폰에 새 버전이 들어갑니다.

## 측정 방식

- **레벨**(현재·평균·최대·최소): 마이크 신호를 **A특성 디지털 필터**(IEC 61672 곡선)로 거른 뒤 표본 하나하나로 계산합니다.
  현재·최대·최소는 Fast(125 ms) 시간 가중, 평균은 LAeq입니다. 시작·초기화 후 0.5초는 필터 안정화를 위해 버립니다.
- **스펙트럼**: Web Audio AnalyserNode의 FFT(블랙만 창) 각 칸에 창 보정과 A특성, 보정값을 더한 칸별 dB(A)입니다.
  모든 칸을 더하면 전체 소음도가 됩니다. 그래서 칸 하나의 값은 전체 소음도보다 낮고, FFT 크기를 키우면 칸이 좁아져 값이 더 낮아집니다.
- **피크**: 약 1초로 평균한 스펙트럼에서 주변(±1/3옥타브)보다 6 dB 이상 튀는 곳을 찾습니다.
- 브라우저의 에코 제거·잡음 제거·자동 음량 조절은 끄고 받습니다.

## 알아 둘 점

- **스마트폰 측정값은 참고값입니다.** 법정 측정(정밀 소음계)을 대신하지 않습니다.
- 휴대폰 마이크는 대략 30–100 dB 범위에서 쓸 만하고, 아주 큰 소리에서는 포화될 수 있습니다(저장된 기록에 경고 표시).
- 화면이 꺼지거나 다른 앱으로 바뀌면 측정이 멈추고, 돌아오면 새로 시작합니다. 측정 중에는 화면이 꺼지지 않게 합니다.
- 기록은 **그 휴대폰 브라우저 안에만** 저장됩니다. 필요하면 엑셀 파일로 보내 두세요.

## 개발

빌드 도구·외부 라이브러리 없이 HTML/CSS/자바스크립트 모듈로 되어 있습니다.

```
index.html              화면 틀 (아래쪽 탭: 분석 / 기록 / 설정)
css/app.css             스타일 (검정 계열, 세로·가로 배치)
js/app.js               화면과 이동 (실시간 분석, 기록, 저장된 기록, 설정)
js/meter.js             마이크 측정 엔진 (Web Audio)
js/level-processor.js   AudioWorklet: A특성 필터, Leq, Fast 최대·최소
js/spectrum.js          FFT 스펙트럼 그래프 (캔버스, 실시간·기록·공유 이미지 공용)
js/gauge.js             바늘 게이지 (SVG)
js/dsp.js               신호처리 순수 함수 (필터 설계, 칸별 dB(A), 피크, 리샘플링)
js/settings.js          설정 저장
js/store.js             기록 저장 (IndexedDB)
js/share.js             공유 이미지, 요약 글, CSV
js/format.js            표시 형식
sw.js, manifest.webmanifest, icons/   오프라인·홈 화면 설치
```

```bash
npm start                       # http://localhost:8080 (localhost 에서는 마이크 허용됨)
npm test                        # 신호처리 단위 테스트 (Node 22, 설치 불필요)
NODE_PATH=$(npm root -g) npm run test:e2e   # 크롬에 테스트 음을 마이크로 넣어 전체 흐름 확인 (playwright 필요)
```

E2E 테스트는 1 kHz·100 Hz 테스트 음(레벨을 아는 WAV)을 가짜 마이크로 넣고, 앱이 표시한 dB(A)와 피크 주파수가 계산값과 맞는지,
일시정지·초기화·저장·보정이 제대로 되는지 확인하고, 세로·가로 화면을 캡처합니다.
